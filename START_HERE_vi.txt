CHÀO MỪNG! Chọn phương thức cài đặt phù hợp:

┌─────────────────────────────────────────────────────────────────────────────┐
│ NGƯỜI DÙNG WINDOWS - Dễ & Nhanh nhất (Khuyến nghị)                         │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Nhấp đúp: SETUP.bat
  2. Theo dõi quá trình cài đặt tự động (2-3 phút)
  3. Hiện thông báo thành công khi hoàn tất
  4. Nhấp đúp: RUN_CVESCAN.bat
  5. Giao diện CVE_Scan sẽ khởi chạy!
  6. Bắt đầu quét!

  ✅ KHÔNG cần dòng lệnh
  ✅ HOÀN TOÀN tự động
  ✅ Cài đặt mọi phụ thuộc
  ✅ Chỉ mất 2 phút!


┌─────────────────────────────────────────────────────────────────────────────┐
│ NGƯỜI DÙNG LINUX / MAC                                                     │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Mở terminal trong thư mục này
  
  2. Chạy cài đặt (tự động):
     chmod +x setup.sh && ./setup.sh
  
  3. Khi xong, khởi chạy ứng dụng:
     python app.py
  
  4. GUI sẽ mở!
  5. Bắt đầu quét!

  ✅ Cài đặt tự động
  ✅ Đủ mọi phụ thuộc
  ✅ Khoảng 3 phút


┌─────────────────────────────────────────────────────────────────────────────┐
│ NGƯỜI DÙNG DOCKER (Windows, Mac, Linux - Khuyến nghị nếu không rành kỹ thuật) │
└─────────────────────────────────────────────────────────────────────────────┘

  Yêu cầu:
    - Tải & cài Docker: https://www.docker.com/products/docker-desktop
    - Miễn phí, mất khoảng 5 phút

  Sau đó:
    1. Mở terminal/PowerShell trong thư mục này
    2. Chạy: docker-compose up
    3. Chờ khởi động xong (thấy "started successfully")
    4. Mở trình duyệt: http://localhost:6080
    5. Giao diện CVE_Scan sẽ hiển thị
    6. Bắt đầu quét!

  ✅ Hoạt động trên MỌI hệ điều hành
  ✅ Không cần Python hay Nmap
  ✅ Mọi thứ cấu hình sẵn
  ✅ Xoá dễ: chỉ cần xoá thư mục

YÊU CẦU HỆ THỐNG (nếu KHÔNG dùng Docker)

  Người dùng Windows:
    ✅ Python 3.11 trở lên
       Nếu chưa có: https://www.python.org/downloads/
    
    ✅ Nmap (để quét mạng)
       Nếu chưa có: https://nmap.org/download
       SETUP.bat sẽ kiểm tra và cảnh báo nếu thiếu

  Người dùng Linux/Mac:
    ✅ Python 3.11 trở lên
       Mac: brew install python3
       Linux: sudo apt-get install python3
    
    ✅ Nmap
       Mac: brew install nmap
       Linux: sudo apt-get install nmap

  Người dùng Docker:
    ✅ Chỉ cần Docker (Docker xử lý tất cả phần còn lại)

CVE_SCAN LÀ GÌ?

  - Công cụ GUI dò quét host và ghép dịch vụ với CVE dùng dữ liệu NVD & CPE
  - Hai phần chính:
    • GUI: nhập mục tiêu, thông tin xác thực, hiển thị tiến trình & kết quả
    • Engine: phát hiện, quét, ghép CVE, xuất báo cáo
  - Kết quả: bản đồ host → cổng → danh sách CVE (id, mức độ, mô tả, CVSS, CPE)


MẸO NHANH

  - Thêm NVD API key trong Settings để lấy dữ liệu CVE mới nhất
  - Bật DB cục bộ nếu không có Internet ổn định
  - Xuất báo cáo CSV/HTML/PDF/JSON từ GUI chỉ với 1 cú nhấp


LIÊN HỆ HỖ TRỢ

  - Vui lòng chạy `verify_installation.py` và gửi log khi báo lỗi
  - Hỗ trợ cấu hình SSH/WinRM, CIDR/IP, và lọc mức độ nghiêm trọng
