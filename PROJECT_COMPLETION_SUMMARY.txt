THE WHOIS TIMEOUT FALLBACK

BEFORE:
  WHOIS timeout → Pipeline crashes ❌
  User sees: Error, scan stops

AFTER:
  WHOIS timeout → Confidence reduced to 0.70 ✅
  Asset still scanned → Complete audit trail
  User sees: ⚠️ WHOIS warning, scan continues

real-world network issues without sacrificing functionality.
