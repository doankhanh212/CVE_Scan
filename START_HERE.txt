WELCOME! Choose your setup method:

┌─────────────────────────────────────────────────────────────────────────────┐
│ WINDOWS USERS - Easiest & Fastest (Recommended)                             │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Double-click: SETUP.bat
  2. Watch the setup run automatically (takes 2-3 minutes)
  3. You'll see a success message when done
  4. Double-click: RUN_CVESCAN.bat
  5. CVE_Scan GUI will launch!
  6. Start scanning!

  ✅ NO command line needed
  ✅ FULLY automated
  ✅ All dependencies installed automatically
  ✅ Takes just 2 minutes!


┌─────────────────────────────────────────────────────────────────────────────┐
│ LINUX / MAC USERS                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Open terminal in this folder
  
  2. Run setup (automated installation):
     chmod +x setup.sh && ./setup.sh
  
  3. When done, start the application:
     python app.py
  
  4. GUI will launch!
  5. Start scanning!

  ✅ Automated setup
  ✅ All dependencies installed
  ✅ Takes about 3 minutes


┌─────────────────────────────────────────────────────────────────────────────┐
│ DOCKER USERS (Windows, Mac, or Linux - RECOMMENDED for non-technical users) │
└─────────────────────────────────────────────────────────────────────────────┘

  Prerequisites:
    - Download & install Docker from https://www.docker.com/products/docker-desktop
    - It's free and takes 5 minutes to install

  Then:
    1. Open terminal/PowerShell in this folder
    2. Run: docker-compose up
    3. Wait for the startup to complete (you'll see "started successfully")
    4. Open browser: http://localhost:6080
    5. You'll see the CVE_Scan GUI
    6. Start scanning!

  ✅ Works on ALL operating systems
  ✅ No Python installation needed
  ✅ No Nmap installation needed
  ✅ Everything pre-configured
  ✅ Easy to remove (just delete folder)

REQUIREMENTS (if not using Docker)

  Windows Users:
    ✅ Python 3.11 or newer
       If not installed: https://www.python.org/downloads/
    
    ✅ Nmap (for port scanning)
       If not installed: https://nmap.org/download
       SETUP.bat will check and warn you if missing

  Linux/Mac Users:
    ✅ Python 3.11 or newer
       Windows: python3 --version
       Mac: brew install python3
       Linux: sudo apt-get install python3
    
    ✅ Nmap
       Mac: brew install nmap
       Linux: sudo apt-get install nmap

  Docker Users:
    ✅ ONLY Docker (it handles everything else!)

TROUBLESHOOTING

  Problem: SETUP.bat fails (Windows)
  Solution:
    1. Make sure Python 3.11+ is installed
    2. Make sure Nmap is installed
    3. Run: python verify_installation.py
    4. See: QUICK_REFERENCE.md for detailed help

  Problem: setup.sh fails (Mac/Linux)
  Solution:
    1. Check Python: python3 --version
    2. Install missing packages:
       Mac: brew install python3 nmap
       Linux: sudo apt-get install python3 nmap
    3. Run verify_installation.py
    4. See: QUICK_REFERENCE.md for detailed help

  Problem: Docker fails
  Solution:
    1. Make sure Docker is installed: docker --version
    2. Make sure Docker is running
    3. See: DISTRIBUTION_GUIDE_COMPLETE.md for help
