STEP 3: CREATE WINDOWS PACKAGE (ZIP FILE)
═══════════════════════════════════════════════════════════════════════════════

Open PowerShell and run:

    cd "C:\Users\dhqkh\Documents"
    
    Compress-Archive -Path CVE_Scan -DestinationPath CVE_Scan_v1.0.zip -Force

Users will:
  1. Download CVE_Scan_v1.0.zip
  2. Right-click → Extract All
  3. Double-click SETUP.bat
  4. Wait 2-3 minutes
  5. Double-click RUN_CVESCAN.bat
  6. Start scanning!

═══════════════════════════════════════════════════════════════════════════════
STEP 4: CREATE LINUX/MAC PACKAGE (TAR FILE)
═══════════════════════════════════════════════════════════════════════════════

If you have WSL or Linux, run:

    cd /mnt/c/Users/dhqkh/Documents
    tar -czf cve_scan_v1.0.tar.gz CVE_Scan/

Or on actual Linux/Mac:

    cd ~/Documents
    tar -czf cve_scan_v1.0.tar.gz CVE_Scan/

This creates: cve_scan_v1.0.tar.gz

Users will:
  1. Download cve_scan_v1.0.tar.gz
  2. Extract: tar -xzf cve_scan_v1.0.tar.gz
  3. Run: chmod +x CVE_Scan/setup.sh && CVE_Scan/setup.sh
  4. Start: python app.py
